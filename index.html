canal-auto

YouTube  Esta herramienta usa los servicios de la API de YouTube (YouTube API Services).

canal-auto es una herramienta personal de escritorio que prepara vídeos divulgativos y, solo después de que su propietario los revise y apruebe, los sube a su propio canal de YouTube con la YouTube Data API v3.

No es un servicio público: solo la usa su propietario, con su propia cuenta de Google.

English

canal-auto is a personal desktop tool that prepares educational videos and, only after the owner reviews and approves them, uploads them to the owner's own YouTube channel using the YouTube Data API v3. It is not a public service and is used only by its owner. By using it you agree to the YouTube Terms of Service.
