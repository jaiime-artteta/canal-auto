Política de privacidad / Privacy Policy

Última actualización / Last updated: 13 de noviembre de 2026

canal-auto usa los servicios de la API de YouTube (YouTube API Services). Al usarla aceptas las Condiciones del Servicio de YouTube y se aplica la Política de privacidad de Google.

Datos a los que accede

Con el permiso youtube.upload, la herramienta solo sube vídeos, miniaturas y sus metadatos (título, descripción, etiquetas) al canal del propietario. Con una clave de API consulta estadísticas públicas de vídeos y canales (visualizaciones, títulos) para analizar temas. No lee datos privados del usuario.

Cómo se usan, guardan y comparten

El token de acceso de Google se guarda solo en el ordenador del propietario (archivo local). Las estadísticas públicas se guardan en local como máximo 30 días para el análisis y luego se borran o actualizan. No se envía ningún dato a terceros, no se vende y no se comparte. No se usan cookies ni se recopilan datos de otras personas.

Cómo borrar los datos y revocar el acceso

Puedes retirar el permiso en cualquier momento en myaccount.google.com/permissions o con el comando subir.py revocar, que además borra el token local. Para pedir el borrado de cualquier dato guardado escribe a jaimefernandezarteta2@gmail.com; se borrará en un máximo de 7 días.

English summary

canal-auto uses YouTube API Services; by using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies. With the youtube.upload scope it only uploads videos, thumbnails and metadata to the owner's own channel; with an API key it reads public video/channel statistics. The OAuth token is stored only on the owner's computer; public statistics are kept locally for at most 30 days. No data is shared with or sold to third parties, and no cookies are used. Access can be revoked at any time at Google security settings; deletion requests: jaimefernandezarteta2@gmail.com (completed within 7 days).
